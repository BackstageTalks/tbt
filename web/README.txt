BlinQ web-app prototype

Deploy:
1. Upload the CONTENTS of this folder to any static hosting.
2. Open index.html.
3. HTTPS is recommended for PWA install/service worker.

Works as a static front-end prototype with no build step and no external dependencies.
Sections: Today, Overview, See All, VIP, Stats, Membership, Profile.
Interactions: navigation, search/filter, pick analysis modal, support widget, PWA install prompt.
