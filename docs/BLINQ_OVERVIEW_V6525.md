# BlinQ v6.5.25 — Overview access parity

- Overview is fixed at the end of the tennis navigation, immediately before BTTS Bonus.
- Admin can enable/disable Overview navigation globally.
- Per membership level: OPEN / VISIBLE LOCKED / HIDDEN.
- Per membership level: visible match count 0–5 or ALL, blur remaining rows, allow/lock match detail.
- Filters and sorting remain available on the Overview page.
- Administrators bypass membership gating unless they explicitly activate Preview as a membership level.
- Active admin preview is now visibly indicated and can be exited with one click.
