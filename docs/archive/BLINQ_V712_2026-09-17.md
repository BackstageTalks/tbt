# BlinQ v7.1.2

## UI
- Results are paginated instead of rendering an effectively endless table.
- Default page size: 50 rows; optional 100 rows.
- Bottom controls: range, total, page size, previous/next page.
- Filter changes reset Results to page 1.
- Existing site background is slightly more visible while preserving contrast.

## Tournament logos
- Broken provider tournament logos now hide cleanly and reveal the local tournament fallback SVG.
- Existing fallback SVG assets were retained; they are present and valid, so re-import is not required to fix the broken-image icon.

## Comeback LIVE
- Public ELITE+ radar status is now a read-only scan (`publish=False`).
- The minute timer remains responsible for publishing WATCH/CONFIRMED alerts.
- This lets radar status keep working even when private insight storage is temporarily unavailable; persistent alerts still require Azure Table Storage or Firestore.

## Provider probe
- Data workflow now sets `PYTHONPATH: api:scripts`, fixing `ModuleNotFoundError: No module named 'tbt'` in provider-probe.

## Validation
- Node syntax check: app.js/auth.js PASS.
- 39 targeted tests PASS.
- Broader local suite excluding Azure API smoke: 372 PASS, 8 FAIL only because local environment lacks pyarrow. GitHub workflow installs pyarrow from requirements-train.
