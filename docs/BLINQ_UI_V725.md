# BlinQ v7.2.5 — banner carousel and background controls

Admin → Bannery now has five permanent hero tabs. Fill Banner 2, then change "Počet aktívnych bannerov" from 1 to 2; the public hero starts rotating automatically. Repeat up to five banners. Delay is selectable from 3 to 10 seconds.

The site background is a single global field shared by all hero slides. It can be uploaded through the existing media upload control. Ambient CSS effects are layered over the background so custom images remain usable without baking visual effects into the file.

The admin visual shell uses one main work-area border rather than nested frames.
