## Follow-up prevention (2026-11-06, independent root-cause audit still open)

A further source review found two additional **verified code gaps**. These
are not proof that the 83% Safonov model output or 3.70 quote was itself wrong:

1. `extract_match_winner_odds` matched player names by **substrings**. "Ann"
   could map "Anna" to the incorrect side. Matching is now limited to an exact
   normalized name or an explicit unambiguous 1/2/home/away selector. Ambiguous
   abbreviated provider names remain unpriced rather than guessing the side.
2. `enrich_current_betting_day_odds` checked betting-day bounds but did not
   exclude matches whose scheduled time had already passed. New pre-match
   quotes are now skipped for started matches without an API request.
   Timestamped winner quotes captured at/after kickoff, or carrying invalid
   explicit timestamps, cannot enter active TOP/VALUE/PRIME on either the
   selector or the canonical TOP serving path. Original snapshots and Results
   remain immutable; missing legacy quote timestamps are not fabricated.

The existing 50-percentage-point price inversion quarantine remains unchanged.
Local prices and their source precedence remain unchanged. New diagnostics
`started_predictions_skipped` and `post_start_quote_quarantined` expose
pre-start data-quality refusals, without altering the raw records.
