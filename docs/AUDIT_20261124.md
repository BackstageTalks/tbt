## Kontroly bez ďalšieho nálezu

- **Oddelenie publikačných dát.** Virtuálny výber pracuje na kópiách (offer_shadow.py:196–209). Pipeline vytvára virtuálne esá samostatne, zachytáva chyby pri výpočte aj mesačnom reporte (pipeline.py:771–784, 818–823, 1772 a 2032). Virtuálne riadky pripája do candidate_snapshot, nie medzi vydané tipy. Pred nahraním sa stále kontroluje existujúci kontrakt Telegramu. V tejto vetve sme nenašli priame odoslanie na Telegram. Živý Telegram ani porovnanie reálnych odoslaných správ neboli súčasťou offline testu.
- **Vyrovnanie platných kontraktov.** offer_shadow.py:265–285 používa winner_id pre TOP/Value, hráčske ID pre výber p1/p2 a pre esá/dvojchyby porovnáva vlastný počet so súperovým. Pri rovnosti superiority je výsledok void. Pre hráčske O/U porovnáva s hranicou správnym smerom. settle_month kontroluje dokončenie, čas, zhodu dvojice hráčov, digest a už započítaný deň. Existujúce testy pokrývajú riadne výsledky a tampering, nie univerzálnu bezchybnosť.
- **Vlastnosti.** tests/test_feature_checkpoints.py:34 a :45 porovnávajú frame s check_exact=True a menia historický rank. Pre tieto vstupy cold/warm replay aj invalidácia prešli. Nie je to dôkaz bitovej identity ľubovoľného modelového artefaktu. Workflow na :146–155 naďalej robí leakage audit a kandidátsky tréning bez --promote. Novou hranicou dôvery je cache popísaná vyššie.
- **Ponuka.** market_selection.py:1282 aplikuje obidve Value podmienky. data.yml:177–179 predvolí ATP,ITF-M, zapnutý serve+return a TOP 1,40. Pravidlá sú konfigurovateľné. Na :1316 sa do lacnejšej zásoby dostanú len inak prípustné tipy; na :1344 sa zásoba použije len pri nedostatku kvalifikovaných TOP. Workflow data.yml:642–651 exportuje uložené admin hodnoty do rovnakého shellu pred spustením pipeline, pri nedostupnosti zachová workflow defaults. Pre TOP platí nesúlad kľúčov vyššie.
- **Prístup.** Štyri nové rozhrania v api/function_app.py:2990, 3014, 3026 a 3044 majú pred spracovaním požiadavky admin kontrolu alebo kontrolu worker tokenu. Pomocná funkcia na :1988 odmietne prázdnu konfiguráciu a porovnáva pomocou compare_digest. V tomto diff-e sme nezistili novú nechránenú admin/worker trasu. Ide o statickú kontrolu zmien, nie test nasadeného gatewaya.
- **Tajomstvá.** Offline rg skontroloval hodnoty tvaru štandardných GitHub tokenov, AWS access-key ID a hlavičky privátnych kľúčov. V pracovnom strome zachytil dva Firebase contract testy s markermi; samotný marker nedokladá privátny kľúč. git log -G nad rozsahom 7ef0b426..09168566 nenašiel zmenu s týmito signatúrami. Claude/README.md:73–74 dokumentuje skorší PAT v chate a heslo záloh; aktívnosť ani rotácia nie sú overené. **Vysoká, ak sú ešte platné:** overiť rotáciu a prístupy bez výpisu hodnôt. Lokálny klon je plytký. Výsledok nevylučuje staršie alebo neštandardne zapísané tajomstvo a žiadne poverenia sme nepoužili na skúšobnú autentifikáciu.
